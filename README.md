# AI Website Builder (Groq + LangChain)

Generate fully functional HTML/CSS/JS websites instantly from a text description using **Groq Cloud** and **LangChain**.

## Features
- 🧠 Natural language to code – describe any site and watch it appear
- 🧩 Structured output – separate HTML, CSS, and JavaScript panels
- ✏️ Live code editor with syntax highlighting (Prism.js)
- 📱 Responsive split-screen UI
- 🚀 Deploy to Vercel with one click

## Tech Stack
- **Backend:** Python, Flask, LangChain, Groq Cloud API
- **Frontend:** HTML, CSS, JavaScript, Prism.js
- **Deployment:** Vercel (free Hobby plan)
